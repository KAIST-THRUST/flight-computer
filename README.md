# Flight Computer

## Introduction

This is the repository for the flight computer of TU-1.f, migrated to PlatformIO.
The original code was compatible with the Arduino IDE and the VSCode Arduino 
extension. However, due to the deprecation of the VSCode Arduino extension, the 
project has been migrated to PlatformIO for better support and maintainability.

## Installation

Clone or download this repository to your local machine.

```bash
git clone https://github.com/KAIST-THRUST/flight-computer.git
```

## Library

The library specification is written in the `platformio.ini` file.
